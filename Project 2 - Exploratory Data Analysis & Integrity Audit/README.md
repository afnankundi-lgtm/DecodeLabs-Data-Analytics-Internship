# Project 2 – Exploratory Data Analysis & Integrity Audit

## Overview

This project focuses on conducting exploratory data analysis and a data integrity audit on an e-commerce dataset using Microsoft Excel and GitHub.

## Objectives

- Perform exploratory data analysis
- Conduct data integrity audits
- Detect and manage pricing anomalies
- Analyze sales and revenue drivers
- Prepare structured executive summaries

## Dataset

- Raw Dataset
- Cleaned Workbook

## Tools Used

- Microsoft Excel
- Git & GitHub

## Techniques Applied

- Central Tendency Evaluation (Mean & Median)
- Interquartile Range (IQR) Outlier Detection
- Correlation Analysis (`CORREL`)
- Statistical Formulas (`QUARTILE.INC`)
- Corporate Report Styling

- Workbook.xlsx
- descriptive_stats.jpg
- Executive Summary.jpg
- README.md

## Result

A fully audited dataset and professional executive summary were successfully prepared and documented for business decision-making.
